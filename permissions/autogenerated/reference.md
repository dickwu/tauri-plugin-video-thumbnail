## Default Permission

Default permissions for the video-thumbnail plugin

#### This default permission set includes the following:

- `allow-generate-thumbnail`

## Permission Table

<table>
<tr>
<th>Identifier</th>
<th>Description</th>
</tr>


<tr>
<td>

`video-thumbnail:allow-generate-thumbnail`

</td>
<td>

Enables the generate_thumbnail command without any pre-configured scope

</td>
</tr>

<tr>
<td>

`video-thumbnail:deny-generate-thumbnail`

</td>
<td>

Denies the generate_thumbnail command without any pre-configured scope

</td>
</tr>

<tr>
<td>

`video-thumbnail:allow-ping`

</td>
<td>

Enables the ping command without any pre-configured scope.

</td>
</tr>

<tr>
<td>

`video-thumbnail:deny-ping`

</td>
<td>

Denies the ping command without any pre-configured scope.

</td>
</tr>
</table>
